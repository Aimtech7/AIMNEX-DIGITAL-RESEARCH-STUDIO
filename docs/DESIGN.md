# Design specification
Reference: design-concept.png (1536 × 1024).
Cool gray #f6f8fa canvas, white sidebar/surfaces, ink #111b2d, muted #526071, teal #096b61. Sans-serif typography, 40px page title, 14–16px UI, 28px panel heading, 6px controls. Outline Lucide icons, 1.7px strokes. White sidebar with selected teal navigation, subtle borders, no decorative imagery, no gradients. Main cases table, four metric strips, recent activity and a pale teal evidence panel.
Allowed primary copy: AIMNEX / DIGITAL RESEARCH STUDIO; Overview; Cases; Evidence vault; Findings; Reports; Settings; Workspace / Cases; Private workspace; Cases; Sample workspace; Turn information into evidence. Follow every lead.; New case; Active cases; Evidence items; Open findings; Reports ready; Search cases; All statuses; CASE; CLIENT; STATUS; EVIDENCE; UPDATED; Recent activity; Your investigation, connected.; Keep sources, findings and reports in one traceable workflow.; Open evidence vault; Aimtech; Analyst.
Architecture: server-owned D1 records + R2 originals; client shell, case table, detail workspace, reusable native controls and modal. Tabs for Overview/Evidence/Findings/Assistant inside cases are required downstream workflow extensions using the same tokens. Mobile sidebar collapses into a scrollable navigation bar; tables retain horizontal scroll. Sample mode switch and persistence status are intentional functional additions. Demo data is isolated from live data and clearly marked. Website checks are bounded, scope-aware server operations; assistant is an explicitly labelled checklist until a model provider is connected.
